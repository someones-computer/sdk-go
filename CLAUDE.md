# The someones.computer_sdk_go working agreement

> This file explains how to *work* in this repo: the Go SDK for the someones.computer API.
> The code is generated by openapi-generator, so fix the spec in the platform repo and
> regenerate rather than hand-editing model files. The style and VCS sections come from the
> shared `.claude/agent-standards` submodule. Bugs and feature requests live in the platform
> repo ([Grey.ooo/Someones.Computer](https://git.grey.ooo/Grey.ooo/Someones.Computer)),
> because this repo's own issue tracker is disabled.

**First action in any session: run `.claude/check-wiring.sh`.** Silence means the wiring is
good. Output means the shared working agreement didn't load. Fix it before you start work.
Every clone and worktree needs `git submodule update --init --recursive`.

## Quality gate

Run these before you push. CI runs the first two (`.github/workflows/ci.yaml`), and the
`pre-commit` and `pre-push` hooks run them once you install it with `mise run hooks`.

| Check | Command |
|-------|---------|
| Vet | `go vet ./...` |
| Build | `go build ./...` |
| Hooks, whole tree | `hk check --all` |

Install the toolchain with `mise install`. `mise.toml` pins `go`, `hk` and `pkl`.
